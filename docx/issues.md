## 4. 搜索功能：前端过滤 vs 后端全文搜索

**现状**:
- 左侧文件树有搜索框，当前实现是**前端过滤** `GET /api/fs/tree` 返回的完整文件树
- 只匹配文件名和路径，不搜索文件内容

**两种方案**:

### 方案 A：保持前端过滤（当前实现）
- ✅ 实现简单，无需额外 API
- ✅ 响应快，不依赖后端
- ✅ 适合小规模文件树（< 1000 文件）
- ❌ 无法搜索文件内容
- ❌ 无法跨文件名匹配（如搜索文件内容中的关键词）

### 方案 B：后端全文搜索 API
- **新增 API**: `GET /api/search?q=xxx`
- 返回匹配的文件路径 + 内容片段 + 匹配行号
- 前端搜索框改为调用后端 API，实时显示结果
- ✅ 支持内容搜索
- ❌ 需要额外的搜索服务或 SQLite FTS 扩展
- ❌ 响应速度依赖数据量

**决策人**: gzy
**状态**: 待定
